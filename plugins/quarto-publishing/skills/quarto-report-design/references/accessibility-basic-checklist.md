# Basic Accessibility Checklist

This is a basic transitional checklist for report design. It is not a full accessibility audit.

## Check

- Headings are logically nested.
- The table of contents is not overloaded by setup or support sections.
- Figures have meaningful captions and, when the output supports it, alt text.
- Tables have clear titles, labels, and readable structure.
- Links use descriptive text.
- Color is not the only carrier of meaning.
- Important conclusions are stated in text, not only encoded in figures.
- Collapsed callouts and appendices do not hide information needed to understand the main argument.
- Acronyms and uncommon terms are defined near first use.
- Reader-facing labels are clear, even when internal code names are ASCII and compact.

## Defer

Defer full publication readiness, PDF accessibility, link checking, visual inspection, and formal accessibility review to future `quarto-accessibility-quality`, or to `quarto-render-troubleshooting` when the task is output verification.
